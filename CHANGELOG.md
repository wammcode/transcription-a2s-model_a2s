# Historial de cambios

Este proyecto sigue el formato de [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y utiliza versionado semántico.

## [0.1.0] - 2026-10-03

### Añadido

- Repositorio Git global para los experimentos de AMT y A2S.
- Política de exclusión para datos fuente pesados, puntos de control, cachés, registros y binarios generados.
- Instantánea recuperable del historial completo de `a2s-transformer` en `control_version/a2s-transformer.bundle`.
- Script para actualizar la instantánea de `a2s-transformer` tras nuevos commits.
- Registro de procedencia de la rama local de `a2s-transformer` y de sus ajustes incorporados.

### Modificado

- Traducción al español de todos los README del árbol de trabajo.
